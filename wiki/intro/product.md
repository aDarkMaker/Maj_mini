# 产品介绍

Maj_Mini 是一个四川麻将（定缺 / 血战到底）的 **playground 与 AI 训练框架**。

它由三部分组成：

- **规则引擎**（`backend/`）：用 Zig 实现完整川麻规则，是纯逻辑、不可变的状态机，可独立用于规则校验或对局模拟，通过 stdio NDJSON 协议暴露给外部。
- **前端编排**（`src/`）：Bun + TypeScript 负责对局编排、终端显示、训练数据生成与模型推理桥接。
- **AI 训练**（`src/ai/` + `agent/`）：通过 rollout 穷举模拟生成监督数据，再由 PyTorch Q 网络学习「该打哪张牌」。

## 核心机制

- **定缺**：开局每人强制绑定一门缺牌，胡牌时手牌不能含该花色；有缺门牌时只能打缺门。
- **血战到底**：一家胡牌后其余玩家继续游戏，直到三家胡牌或流局；已胡牌玩家不再参与付钱。
- **流局结算**：墙摸空且未胡满三家时，对剩余未胡玩家查叫（无叫赔有叫）与花猪（三花色赔非花猪）。

## 适用场景

- 学习/验证川麻规则判定逻辑
- 训练一个会打牌的 AI bot
- 作为强化学习/监督学习的教学 playground

::: tip
引擎与训练完全解耦：你可以只用引擎跑对局，也可以只用训练出的模型做推理，二者分别通过 NDJSON 协议（引擎）与 JSON 协议（`predict.py`）桥接。
:::
