# 功能特性

## 引擎

| 能力 | 说明 |
| --- | --- |
| 胡牌判定 | 标准牌型（4 搭子 + 1 对）与七对，递归枚举 |
| 定缺强制 | `getValidDiscards` 在有缺门牌时只允许打缺门 |
| 碰 / 杠 / 胡 | 暗杠、明杠、加杠，杠后补牌；自摸与点炮 |
| 番数换算 | 清一色 / 七对 / 大对子 / 龙七对，倍数封顶 |
| 流局结算 | 查叫（无叫赔有叫）、花猪（三花色赔非花猪） |
| 可复现对局 | 种子化 LCG 洗牌，相同种子 → 相同牌局 |

## AI 训练

| 能力 | 说明 |
| --- | --- |
| Rollout 数据生成 | 穷举每手可打牌 × N 次模拟 → 平均 reward |
| 30 维特征 | 27 手牌计数 + 3 定缺 one-hot |
| 相对优势目标 | `--relative-advantage`，学习手内相对优劣 |
| 验证集 + 早停 | 防过拟合，自动恢复最优权重 |
| 跨平台推理 | bot 自动定位 venv Python，`uv run` 兜底 |

## 工程化

- TypeScript 严格模式 + `bun run typecheck`
- 41 个单元测试（`bun run test`）覆盖六大模块
- GitHub Actions CI（typecheck + test + 训练冒烟）
- Mermaid 图文档化架构与数据流
